## Projetos em destaque

### Verify — Análise e validação de documentos com OCR e IA aplicada

Projeto atual da **Residência IV**, em parceria com a **Universidade Tiradentes (Setor DAAF)**.

O Verify é um sistema para análise e triagem de documentos acadêmicos, como atestados, históricos e certificados. O projeto utiliza conceitos de **OCR**, **IA aplicada**, validações por regras e organização de pipeline para apoiar a interpretação e verificação de documentos.

**Minha atuação envolve:**

- Organização conceitual do fluxo de análise com OCR, back-end e IA
- Discussão de arquitetura para uso mais eficiente de LLMs
- Separação entre extração objetiva, validações por regras e interpretação assistida por IA
- Estudo e aplicação progressiva de conceitos como downstream tasks, prompt design e JSON estruturado
- Apoio na estruturação do back-end e integração com o restante do sistema

**Tecnologias e conceitos:** FastAPI, Python, OCR, LLMs, prompt design, JSON estruturado, Vue.js, APIs REST

**Repositório:** [unit-squad8/Squad_8-UNIT](https://github.com/unit-squad8/Squad_8-UNIT)  
**Ainda não está "deployado"**

### Sistema de gerenciamento de encomendas — Tokseg

Projeto desenvolvido durante a **Residência II**, desenvolvido para a Tokseg, em contexto condominial, com foco no gerenciamento de encomendas e apoio à organização de entregas e retiradas.

A solução foi construída com back-end em **Java** e **Spring Boot**, utilizando APIs REST, JPA e banco de dados relacional. O projeto permitia registrar, consultar e gerenciar encomendas, contribuindo para um fluxo mais organizado de controle interno.

**Minha atuação envolveu:**

- Desenvolvimento de funcionalidades back-end com Java e Spring Boot
- Criação e organização de APIs REST
- Integração com banco de dados relacional utilizando JPA
- Apoio na modelagem das entidades e regras principais do sistema

**Tecnologias:** Java, Spring Boot, JPA, APIs REST, banco de dados relacional

**Observação:** o repositório não está disponível publicamente, pois estava hospedado em uma conta de terceiro que foi encerrada.
